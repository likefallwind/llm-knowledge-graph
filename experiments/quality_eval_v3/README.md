# 同书来源支持质量试评 v3

本轮执行协议，2026-09-12。**预先固定规则，不依据方法得分改权重。**

## 范围与抽样

使用《动手学深度学习》四个已冻结 submission。每方法均匀无放回抽 20 个实体和 20 条断言；seed=20260912，先按 id 排序，各方法/种类独立随机流。AutoSchemaKG 延续已修正基线质量比较的语义关系子集，排除 `is participated by` 事件参与辅助边；实体样本仍包含事件。样本组成和排除数写入 manifest，不声称覆盖全部事件图功能。

先执行 13 个受控校准题，再启动 160 个正式试评样本；任一预设校准期望未通过，停止在校准待复核状态，不生成方法排名。校准是研究者编写的合成逻辑测试，含基于本书 P003033 的汇聚层例子，不是独立人工金标。不得根据校准结果修改测试样本或预期以确保通过。

冻结脚本、提示、输入任务、私有映射、来源和四个 submission 哈希。裁判只见样本内容和提交的完整引用段落，看不到方法名；格式可能暴露身份。模型 MiniMax-M3，官方接口，单进程四个工作线程，每次 HTTP 还必须持有共享四槽锁，重试也受此限制。每次请求最多 3 次尝试，审核拦截记缺失继续，凭据/额度终止错误由传输层禁止后续 HTTP。长输出或非法 JSON 不计成功。保留真实请求审计，不保存密钥。

## 本轮真正报告的指标

- 实体身份来源支持比例：名称所指、边界、局部含义受到引用支持的实体 / 全部抽样实体。类型支持另报。本轮不核验全部别名，不评全局归并。
- 定义支持：原生定义可用率、有定义样本的完整定义支持率、有且有据的定义占全部实体比例。没有原生定义的占位文字转为 null，不判为幻觉。
- 断言支持：分别核验核心关系以及完整描述/条件，并拆为不重复原子陈述；严格完整支持要求核心、全部描述和全部原子均通过。原子支持比例先在记录内求均值，再跨记录求均值，避免长描述获得更大权重。该均值仍受裁判拆分影响，需人工复核。
- “具体且有据”是输出信息粒度诊断：完整断言有来源支持，且确实表达超出普通关联的事实。**不是金标事实召回，也不把源文本本来宽泛的事实判错。** GraphRAG 的原生描述与其他方法描述同等计入；具体谓词若错误不得用正确描述抵销。
- 引用可解析率、裁判估计的有效引用比例、充分支持样本上的引用段落数/字符数。支持性与阅读负担分别报告；不同方法抽样事实不同，不能把长度差全归因为溯源机制。
- quote 的 NFKC/空白忽略逐字对齐率单独报告；不对齐不自动等于伪造，可能是释义。**本轮裁判读取完整父段落，长度始终按去重父段落计数；不能据此声称短引文预算下也足以支持。**

来源支持失败区分明显矛盾与缺少证据，不能把所有“不支持”称作事实错误。实体与关系任务分别使用其自身提交的 evidence；不替它们检索或追加节点证据。GraphRAG/其他方法存在 chunk 映射溯源，应正常评分，不能按有无特定数据库表判断。

未判定/失败/审核跳过/超过 120000 来源字符上限均保留在固定样本分母，另报覆盖；不截断来源、不因长度换样。进行中的支持率只是已确认比例的下界。空条件分母记 N/A，不给满分。完成后也需将未判定量与支持率一起解释，不把技术失败当作确定的语义错误。

## 保留与延后

历史 200 条断言质量、48 个检索探针保留为诊断，不覆盖旧分数，不将它们合成任意加权总分。节点/边数量、非空 evidence 比例、谓词种类不承担主质量排名。

本轮只有同模型裁判的输出抽样，20 个样本相差一项即 5 个百分点，不能宣布统计显著或论文结论。正式论文仍需独立源文本窗口金标、实体识别与具体事实 P/R/F1、身份归并、共同事实证据比较、双人盲标/独立裁判校准，以及按来源窗口聚类的区间估计。真实短跨度预算评测须限制裁判只读该跨度后重新判定。正式召回和结构查询均不在本次试评里伪造分数。

## 使用

准备新目录：`python3 experiments/quality_eval_v3/evaluate.py prepare --run tmp/quality-v3-RUN`

执行冻结版本：`python3 tmp/quality-v3-RUN/evaluate.py run --run tmp/quality-v3-RUN`

查看 `progress.json`、`calibration-report.json`、`summary.json`、`REPORT.md` 和全部样本的 `review.json`。断点执行只复用已有结果；失败样本不默默重试。运行脚本不修改历史图谱或评测。
